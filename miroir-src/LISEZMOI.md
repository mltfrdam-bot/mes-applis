# Miroir — sources
Code de la page `miroir/` (afficher et piloter le téléphone depuis la tablette, par câble USB).
- `main.js` : le programme. Pour refabriquer `miroir/app.js` : `npm install` puis `npm run build`.
- Briques libres : Tango / ya-webadb (licence MIT), serveur scrcpy v3.3.3 (licence Apache 2.0). Voir `miroir/LICENCES.txt`.
