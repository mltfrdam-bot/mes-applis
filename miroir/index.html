📱 Miroir

Afficher et piloter ton téléphone depuis la tablette

❓ Comment se connecter sans fil
  1. Sur le téléphone : active le point d'accès.
  2. Sur la tablette : connecte le Wi-Fi au point d'accès du téléphone.
  3. Après chaque redémarrage du téléphone : branche le câble entre la tablette et le téléphone. Miroir affiche le téléphone ; suis la barre du haut : ① déverrouiller, ② allumer le point d'accès, ③ passer en sans fil. Débranche quand c'est écrit.
  4. Ici, appuie sur 📶 Connecter sans fil.

L'adresse du téléphone est trouvée toute seule. Ne la tape que si la connexion échoue (elle est affichée par Miroir dans Chrome, fenêtre « Sans fil »).

❓ Avant la première connexion
  1. Sur le téléphone : Débogage USB activé (Options de développement).
  2. Ferme Tango s'il est ouvert dans un autre onglet.
  3. Branche le câble USB-C entre la tablette et le téléphone.
  4. Appuie sur Connecter, choisis le téléphone dans la liste, puis Connexion.
  5. Sur le téléphone, coche « Toujours autoriser » puis Autoriser (une seule fois : Miroir a sa propre clé, différente de Tango).

Astuce : menu ⋮ de Chrome → Ajouter à l'écran d'accueil. Miroir s'ouvrira alors en plein écran, comme une vraie appli.

⚙️ Réglages

📶 Passer en sans fil

  1. Une seule fois : enregistre la clé pour l'appli (bouton ci-dessous), puis télécharge et installe l'appli Miroir.
  2. Appuie sur Activer le sans fil.
  3. Débranche le câble. Connecte la tablette au point d'accès du téléphone.
  4. Ouvre l'appli Miroir et appuie sur 📶 Connecter sans fil.
